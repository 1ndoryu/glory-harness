## 119A-5 F3 parcial - Blur de meta solo confirma con cambios (12-09)

**Bug:** escribir un mensaje normal creaba una meta sin usar `/meta`.
Causa: `confirmarEdicion` disparaba `onMetaCambiada` en cada `blur` aunque el
texto no hubiera cambiado; al enviar, la entrada recupera el foco y el `blur`
fijaba (caja con texto) o limpiaba (caja vacía) en silencio.

**Fix** (`desktop/ui/src/componentes/panelMeta.ts`, commit `5fea82e`):
`ultimoConfirmado` como línea base — el `blur` solo confirma si el texto
cambió, y `sincronizarCaja` (sync programático) actualiza la base para no
re-disparar. `tsc` EXIT 0 + `vite build` OK; HMR recargó la ventana del
`tauri dev` en marcha. Resto de F3 (distinguir «sin meta») sigue abierto.
