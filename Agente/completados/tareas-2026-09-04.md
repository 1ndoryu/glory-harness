## 039A-1: Corrección de los 7 hallazgos del primer `tauri dev` (H1–H7)

- Qué: primer arranque real de la app Tauri con el backend in-process; el usuario
  señaló en vivo 7 problemas. Este bloque los corrige en backend (Rust) y
  frontend (TS vanilla). Hallazgos y detalle en
  `Agente/documentacion/hallazgos-primer-tauri-dev-2026-09-04.md`.
- Correcciones (resumen; detalle por hallazgo en la documentación):
  - H1 — panel meta: `panelMeta.mostrar(visible)` + CSS `.oculto` +
    `sincronizarPanelMeta()` (visible solo con meta o en modo `meta`).
  - H2 — mensaje no visible al enviar: `real.ts` baja el scroll al añadir el
    mensaje del usuario y en cada evento (token/tool_start).
  - H3 — workspace incorrecto: backend persiste el workspace resuelto; el campo
    del modal parte vacío y `onSesion` lo rellena con `info.workspace` real.
  - H4 — conversación nueva en cada arranque: backend reutiliza la última
    conversación no archivada; front carga `candidatas[0]` (sin saltar a una 2ª).
  - H5 — título no auto-generado: `enviar_turno` genera nombre breve del primer
    mensaje; al terminar el turno el front refresca sidebar + cabecera.
  - H6 — resumen de acción no reaparece al recargar: `cargar_conversacion`
    devuelve `acciones` (`AccionRecuperada`) y `pintarHistorial` repinta los
    bloques `.herramienta` intercalados (user → acciones → assistant).
  - H7 — selector de razonamiento: botón real con menú Bajo/Medio/Alto en
    `entrada.ts`; el valor viaja al backend (`abrir_sesion`/`reconfigurar_sesion`
    y `OpcionesTurno.razonamiento`) y se persiste (`nivelRazonamiento`);
    barra ↔ modal comparten el nivel.
- Archivos (frontend): `desktop/ui/src/main.ts`, `componentes/entrada.ts`,
  `componentes/panelMeta.ts`, `estilos/panelMeta.css`, `dominio/opciones.ts`,
  `tauri/real.ts`. (Backend: cambios de sesión/turno/título/acciones ya
  compilados vía `tauri dev` en el bloque previo, en `desktop/src-tauri/src/main.rs`.)
- Evidencia:
  - `npm run type-check` (desktop/ui): limpio.
  - `npm run build` (desktop/ui): PASS (24 módulos, JS 41.5 KB gz 14 KB).
  - Verificación visual en navegador (VITE_MOCK=1, :8760): H1 panel meta se
    oculta en modo predeterminado y aparece en modo `meta`; H7 el selector de
    razonamiento abre menú y cambia el nivel (Medio → Alto).
  - Compilación Rust del backend verificada en el bloque previo (`tauri dev`
    watch) con cambios H3/H4/H5/H6/H7 del backend.
- Decisiones/gotchas:
  - `pintarHistorial` asigna cada acción al ÚLTIMO user con `creado_en <=
    turno_en` (tolerante a segundos compartidos entre turno y siguiente user);
    las residuales (turno sin user persistido) se muestran al final.
  - El mock de navegador no replica el IPC Tauri; la validación E2E completa
    (enviar → streaming → tools → aprobación → `turno-fin`) queda pendiente en
    la ventana real (`tauri dev`).
